# Задача для ассистента (занятие 7)

Маленькая, проверяемая, выполняется в папке проекта `gift-helper` через Hermes → OpenCode.
YOLO не включаем, файлы не удаляем.

## Текст задачи (копировать целиком)

> В проекте gift-helper через opencode добавь на экран результата кнопку «Скопировать идеи».
> По нажатию она копирует в буфер обмена названия пяти карточек, которые сейчас видны
> на экране, по одному в строке. После копирования покажи под кнопкой сообщение
> «Скопировано» на 2 секунды. Если буфер обмена недоступен — покажи те же названия
> через prompt(). Тексты кнопки и сообщения — на pt/ru/en в объекте `T` в `script.js`,
> как остальные. Существующие `id` не меняй, новые подарки не добавляй, файлы не удаляй.
> Покажи `git diff` и скажи, как проверить.

## Как проверить результат

1. `node --check script.js` — синтаксис без ошибок.
2. Открыть сайт → 10–13 → LEGO + игры → девочка → нажать «Скопировать идеи».
   В буфере обмена ровно 5 строк с названиями карточек, под кнопкой появилось «Скопировано».
3. Переключить язык на RU и EN — кнопка и сообщение переводятся, названия в буфере
   соответствуют выбранному языку.
4. Нажать «Вперёд →» → скопировать ещё раз — в буфере новая пятёрка, а не старая.
5. Кнопки «← Назад», «Вперёд →» и «Начать заново» работают как раньше, старые `id` на месте.

## Чего в задаче нет (специально)

- Никаких «улучши всё», «сделай красивее», «добавь рейтинг и чат».
- Никаких изменений в `data.js`, `style.css`-структуре и `index.html`-разметке экранов
  (кроме одной новой кнопки).
- Никакой отправки данных наружу: только буфер обмена локально в браузере.
