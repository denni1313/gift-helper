# AGENTS.md — правила проекта Gift Helper

1. **Только статика.** HTML + CSS + JS, без библиотек, фреймворков, сборки и сервера.
   `index.html` должен открываться двойным кликом и работать так же на GitHub Pages.
2. **Минимальные правки, по одной задаче.** Не меняй структуру экранов, `id` в `index.html`
   и набор файлов без прямой просьбы. Файлы не удаляй.
3. **Три языка всегда.** Любой текст интерфейса живёт в объекте `T` в `script.js` —
   добавляй ключ сразу в `pt`, `ru` и `en` с одинаковым именем.
4. **Подарки — только в `data.js`.** Теги берутся из списка `INTERESTS` в `script.js`,
   возрастные группы — 1–4 (6–9, 10–13, 14–17, 18+), у каждого подарка `name` на трёх языках.
   Новый подарок без валидного тега или возраста ломает подбор.
5. **Проверяй перед сдачей.** `node --check script.js` и `node --check data.js`,
   затем вручную сценарий «старт → возраст → интересы → пол → результат» на трёх языках.
   В коде не должно быть ключей, паролей, чужих телефонов, адресов и фото.
